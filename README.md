# AS Art Gallery

Dedicated art gallery of Mirza Ahmed Sarwar Hussain (AS) — 
39 hand-drawn pieces and counting. Monochrome ink portraits 
and vivid pop-culture art. Based in Hyderabad.

🔗 Live site: https://asartsgallery.lovable.app

## About
Built with Lovable.dev. Features two sectors — Monochrome 
and Vivid — spanning anime, football, and Bollywood subjects.
All pieces hand-drawn on A4 cartridge paper using graphite, 
ink, and alcohol markers.
